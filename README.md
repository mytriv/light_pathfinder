# Light Pathfinder games

This repository contains three browser games, a preserved original RPG Maker XP project, and the files for the GitHub Pages hub.

- [Light Pathfinder — HTML5 port](https://mytriv.github.io/light_pathfinder/LightPathfinder/)
- [Light Pathfinder JS — custom engine](https://mytriv.github.io/light_pathfinder/LightPathfinderJS/)
- [SiegSim — endless arena](https://mytriv.github.io/light_pathfinder/SiegSim/)
- [Original RPG Maker XP project](https://github.com/mytriv/light_pathfinder/tree/main/Original/)

Each playable build is self-contained in a folder with its own `index.html`. The root `index.html` is the GitHub Pages landing page.
